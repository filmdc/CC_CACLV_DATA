## 1. Introduction

### What is CAP TRACK?

CAP TRACK is a comprehensive data management platform designed specifically for Community Action Partnership agencies. It helps organizations track participants, manage programs and services, monitor progress through work plans, and generate required CSBG (Community Services Block Grant) reports.

### Key Features

- **Participant & Household Management**: Track client demographics and household information
- **Program & Service Tracking**: Manage various programs and their associated services
- **Enrollment Management**: Track participant enrollments in programs and services
- **Work Plan Management**: Set annual goals and track progress
- **CSBG Reporting**: Generate required federal reports automatically
- **Role-Based Access Control**: Manage user permissions and program access

### System Requirements

- Modern web browser (Chrome, Firefox, Safari, Edge)
- Stable internet connection
- JavaScript enabled

## 4. Participant Management

### Viewing Participants

1. Click "Participants" in the sidebar
2. Use the search bar to find specific participants
3. Click on a participant's name to view details

### Adding a New Participant

1. Click "Create Participant" button
2. Fill in required information:
   - First Name*
   - Last Name*
   - Date of Birth*
   - Gender*
   - Race/Ethnicity
   - Contact Information
3. Select or create household association
4. Click "Create Participant"

### Editing Participant Information

1. Navigate to the participant's detail page
2. Click "Edit" button
3. Update necessary fields
4. Click "Update Participant"

### Important Fields for CSBG Reporting

Ensure these fields are completed for accurate reporting:
- Date of Birth
- Gender
- Race/Ethnicity

## 5. Household Management

### Understanding Households

Households represent family units and are crucial for:
- Income calculations
- Federal poverty level determinations
- CSBG reporting requirements

### Creating a Household

1. Click "Households" in the sidebar
2. Click "Create Household"
3. Enter household information:
   - Household Code (auto-generated if left blank)
   - Address Information
   - Phone Numbers
4. Click "Create Household"

### Adding Members to Households

1. From the household detail page
2. Click "Add Member"
3. Select existing participant or create new
4. Specify relationship to head of household

### Household Income Management

1. Navigate to household detail page
2. Click "Update Income"
3. Add all income sources:
   - Source Type
   - Amount
   - Frequency
4. System automatically calculates:
   - Total household income
   - Federal poverty level percentage

## 8. Enrollment Management

### Viewing Enrollments

1. Click "Enrollments" in the sidebar
2. Filter by:
   - Program
   - Service
   - Status
   - Date Range

### Creating Enrollments

1. Click "Create Enrollment"
2. Select participant
3. Choose program
4. Select service(s)
5. Set enrollment date
6. Click "Create Enrollment"

### Managing Enrollment Status

Enrollments can have the following statuses:
- **Active**: Currently enrolled
- **Completed**: Successfully finished
- **Withdrawn**: Left before completion
- **Waitlisted**: Awaiting available slot

### Bulk Enrollment

For group enrollments:
1. Click "Bulk Enroll"
2. Select multiple participants
3. Choose program and services
4. Set enrollment date
5. Click "Enroll Selected"

## 9. Work Plans and Goals

### Understanding Work Plans

Work plans are annual planning tools that:
- Set measurable goals for programs
- Track progress throughout the year
- Support funding requirements

### Creating Work Plans

1. Navigate to "Programs & Work Plans"
2. Click "Manage Work Plans"
3. Click "Create Work Plan"
4. Enter:
   - Work Plan Name*
   - Associated Program*
   - Year*
   - Description
5. Click "Create Work Plan"

### Managing Work Plan Goals

1. From work plan details, click "Manage Goals"
2. Click "Create Goal"
3. Enter:
   - Goal Name*
   - Target Number*
   - Associated Service (optional)
   - Description
4. Click "Create Goal"

### Tracking Progress

Goals automatically track:
- **Service-Specific Goals**: Count enrollments in specific service
- **Program-Wide Goals**: Count all program enrollments
- **Progress Percentage**: Actual vs. Target

### Syncing Goal Data

To update goal progress:
1. Click "Sync" button on individual goal
2. Or click "Sync All Goals" to update all at once
3. System pulls latest enrollment data

## 10. Reports and Analytics

### Available Reports

#### CSBG Reports
- **Module 4 Section A**: Participant Demographics
- **Module 4 Section B**: Household Characteristics
- **Module 4 Section C**: Services Provided
- **Custom Date Range Reports**

#### Management Reports
- **Enrollment Summary**: By program and service
- **Participant Activity**: Individual participation history
- **Work Plan Progress**: Goal achievement tracking

### Running Reports

1. Click "Reports" in the sidebar
2. Select report type
3. Choose date range or filters
4. Click "Generate Report"
5. Export options:
   - View on screen
   - Download as CSV
   - Download as PDF

### Report Best Practices

- Run reports monthly to catch data issues early
- Verify participant demographics are complete
- Ensure all services are properly recorded
- Review work plan progress quarterly

## 12. Troubleshooting

### Common Issues and Solutions

#### Login Problems
- **Forgot Password**: Click "Forgot your password?" on login page
- **Account Locked**: Contact system administrator
- **Invalid Credentials**: Ensure caps lock is off

#### Data Entry Issues
- **Required Fields**: Look for red asterisks (*)
- **Validation Errors**: Check format requirements
- **Duplicate Entries**: Search before creating new records

#### Performance Issues
- Clear browser cache
- Check internet connection
- Try different browser
- Contact support if issues persist

### Getting Help

#### In-Application Help
- Hover over (?) icons for field descriptions
- Check validation messages for guidance

#### Support Contacts

1. **Data Quality**

   - Update information regularly
