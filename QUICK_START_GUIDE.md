# CAP TRACK Quick Start Guide

## For New Users - Get Started in 10 Minutes!

### Step 1: Log In
- Go to your CAP TRACK URL
- Enter your email and password
- Click "Log in"

### Step 2: Navigate the Dashboard
The sidebar has everything you need:
- 🏠 **Dashboard** - Your home base
- 👥 **Participants** - Client records
- 🏘️ **Households** - Family units
- 📋 **Programs & Work Plans** - Services hub
- 📝 **Enrollments** - Track participation
- 📊 **Reports** - Generate reports

### Step 3: Add Your First Participant

1. Click **Participants** → **Create Participant**
2. Fill in the basics:
   - Name (First & Last)
   - Date of Birth
   - Gender
   - Contact info
3. Click **Create Participant**

### Step 4: Create a Household

1. Click **Households** → **Create Household**
2. Add:
   - Address
   - Phone number
   - Household members
3. The system auto-generates a household code

### Step 5: Enroll in a Service

1. Click **Enrollments** → **Create Enrollment**
2. Select:
   - Participant
   - Program
   - Service
   - Start date
3. Click **Create Enrollment**

### Step 6: View Reports

1. Click **Reports**
2. Select report type
3. Choose date range
4. Click **Generate Report**

## Key Things to Remember

### 🔴 Required Fields
Look for red asterisks (*) - these fields must be completed

### 🔍 Search is Your Friend
Use the search bars to quickly find participants, households, or services

### 💾 Save Often
Changes are saved when you click update/create buttons

### 📅 Keep Data Current
Update participant information monthly for accurate reporting

### 🔐 Security First
- Log out when done
- Don't share passwords
- Report any issues

## Common Tasks

### Find a Participant
1. Go to Participants
2. Type name in search box
3. Click on their name

### Update Contact Info
1. Find the participant
2. Click "Edit"
3. Update information
4. Click "Update Participant"

### Check Enrollments
1. Go to participant detail page
2. Scroll to "Active Enrollments"
3. View all current services

### Run a CSBG Report
1. Click Reports
2. Select "CSBG Module 4"
3. Choose section (A, B, or C)
4. Select date range
5. Generate report
